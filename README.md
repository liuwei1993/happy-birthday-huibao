# 惠宝，生日快乐

写给王夕惠（惠惠 / 惠宝）的生日祝福站。

## 本地开发

```bash
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。

## 部署到 Vercel

1. 打开 [vercel.com/new](https://vercel.com/new)
2. Import 本仓库 `liuwei1993/happy-birthday-huibao`
3. Framework Preset 选 **Next.js**，直接 Deploy
4. 部署完成后可在 Project Settings → Domains 绑定自定义域名

或用 CLI：

```bash
npx vercel
```

## 技术栈

- Next.js (App Router)
- Tailwind CSS v4
- 部署目标：Vercel
